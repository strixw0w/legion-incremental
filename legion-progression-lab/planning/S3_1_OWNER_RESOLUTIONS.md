# S3.1: owner rule resolutions

**Version 1.0, 2026-11-14.** Source: the owner's "S3.1 Final Acceptance and S4 Authorisation" §3.

This document records the owner's decisions on the twelve S3.1 rules (`planning/S3_1_RESOLUTIONS.md` v1.0, S3.1-R01 … R12). It does not change the historical register (`docs/DECISION_REGISTER.md`), the S3 owner resolutions (`planning/S3_OWNER_RESOLUTIONS.md` v1.0) or any earlier resolution. All of those remain in force.

**No numerical coefficient is promoted to approved final content.**

| Rule | Subject | Owner decision |
|---|---|---|
| S3.1-R01 | Crafting eligibility | **Approved, subject to the dead-hero correction.** The hero is also refused during the respawn delay (`CRAFTER_DEAD`; S3 acceptance addendum, `evidence/s3-acceptance/ADDENDUM.md`). Travel, a pending engagement and regeneration are explicitly allowed. |
| S3.1-R02 | Recipe validation | **Approved:** aggregate recipe and recoverable-material validation. |
| S3.1-R03 | Effective damage | **Approved:** fractional attribution and its precision contract. The legacy integer fields are retained for historical comparisons. |
| S3.1-R04 | First simple crafted item | **Approved.** |
| S3.1-R05 | First crafted equipment equipped | **Approved.** |
| S3.1-R06 | Meaningful combat equipment upgrade | **The original metric is preserved.** A distinct metric, "meaningful upgrade over already equipped combat equipment", is added for later calibration (registered in S4). |
| S3.1-R07 | First Copper combat item equipped | **Approved.** |
| S3.1-R08 | Capacity and utilisation | **Approved.** |
| S3.1-R09 | Excess gathering | **Two measures, never conflated:** (a) gathered-but-unconsumed stock, as implemented in S3.1; (b) production beyond the declared planned demand. The documented S3.1 deviation is preserved: S3.1 reported only (a), for every policy. |
| S3.1-R10 | Shortage types | **Approved.** |
| S3.1-R11 | Combat-effective equipment value | **Approved as a diagnostic equipment-effect index.** It is not a complete economic valuation. |
| S3.1-R12 | Investment payback | **Approved as the EXP payback metric.** Other payback objectives are permitted if declared in advance. |
